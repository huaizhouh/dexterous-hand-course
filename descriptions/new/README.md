# 三指绳索驱动灵巧手：CAD 结构初版

本目录提供可直接导入 SolidWorks 的 STEP AP214 三维装配模型。结构为一根对向指与两根并列指，每指两个被动转动关节、独立的一根屈曲绳，共三路牵引、六个关节。红色实体表示绳索走向。

模型实际读取、转换并复用了 `../support_frames/` 中的零件实体，不是根据名称重新画出的外观近似。原始 `.SLDPRT` 文件没有修改。它是基于现有支架尺寸的结构设计，与 `underactuated_soft_3_finger_hand.xml` 中的胶囊体教学模型不同。

## 打开哪个文件

| 文件 | 用途 |
| --- | --- |
| `tendon_three_finger_hand_open_single_part.step` | 张开姿态的单零件、多实体版，Windows SolidWorks 查看整机时优先使用 |
| `tendon_three_finger_hand_grasp_ready_single_part.step` | 预弯曲姿态的单零件、多实体版 |
| `tendon_three_finger_hand_open.step` | 完全张开姿态，推荐首先打开 |
| `tendon_three_finger_hand_grasp_ready.step` | 近端关节 18°、远端关节 32° 的预弯曲姿态 |
| 同名 `.stl` | 网格版本，仅用于外形预览 |
| 同名 `.png` | 对应 STEP 几何的预览图 |
| `source_step/` | 全部 12 个原始零件的 STEP 转换结果及转换、几何检查报告 |
| `modified_parts/small_u_drilled.step` | 在小 U 连接件副本上增加安装孔、导绳孔的加工版本 |
| `custom_parts/` | 新增手掌、转接板、指尖板、接触垫、衬套、转轴、绳索锚点的单独 STEP |
| `bom.csv` | 装配模型中的零件种类、数量、来源 |
| `assembly_manifest.json` | 各零件变换矩阵、关节轴线、绳路坐标及长度，单位 mm |
| `validation_report.json` | 两个交付 STEP 重新导入后的实体与干涉检查结果 |
| `motion_clearance_report.json` | 张开至预弯曲之间七个中间姿态的干涉检查 |
| `build_hand.py` | 可修改、重新生成模型的参数化源码 |

在 SolidWorks 中通过“打开”选择 `.step` 文件。文件包含装配层级、零件名称和颜色；具体以当前版本的 STEP 导入设置为准。STEP 使用毫米单位，STL 不携带单位信息，导入 STL 时应选择毫米。

上述装配层级、名称和颜色指原来的装配版 STEP。新增 `_single_part.step` 只有一个产品节点、58 个实体，没有装配零件层级，不保留原装配的各零件配色，几何、尺寸和姿态相同。

如果 Windows SolidWorks 打开装配版时逐个创建零件窗口，可能是导入器在拆分其 58 个装配组件。查看整机时优先使用 `_single_part.step`，并在导入选项中保持文件结构；不要选择“将多个实体作为零件导入 / Import multiple bodies as parts”，该选项仍会把多实体版拆成装配。

也可以对原装配版在“文件 → 打开 → STEP → 选项”的装配结构映射中选择“将装配体作为多实体零件导入 / Import assembly as multiple body part”。若反复出现的是导入诊断、模板或错误对话框，则应按具体提示处理，不能仅凭窗口数量判断模型损坏。选项说明参见 [SolidWorks 官方 STEP 导入文档](https://help.solidworks.com/2024/english/SolidWorks/sldworks/t_reading_step_iges_acis_sw.htm)。

STEP 不包含 SolidWorks 原生草图、特征树、装配配合或运动驱动。需要运动时，可依据 manifest 中的关节轴线添加转动配合。两个 STEP 是同一结构的不同静态姿态，无需叠加导入。

## 复用和新增的结构

每个姿态包含 58 个实体，其中 24 个为原有零件的实例（包含 6 个钻孔副本），31 个为新增结构件，3 个为绳索。

| 来源零件 | 数量 | 作用 |
| --- | ---: | --- |
| 小 U 连接件 | 6 | 根部和指间关节的内侧固定支架，使用新增孔的副本 |
| 长 U 支架 | 3 | 近端指节 |
| 短 U 支架 | 3 | 远端指节 |
| 金属主舵盘 | 6 | 关节外侧法兰，保留原有几何 |
| 金属从舵盘 | 6 | 关节另一侧法兰，保留原有几何 |

手掌为 160 × 190 × 8 mm，三个支座再抬高 8 mm。两根并列指的根部间距为 76 mm，与对向指根部的前后间距为 135 mm。尺寸由现有支架的宽度和预弯曲避让需求决定，没有把原零件缩放成小型手指。

长 U 支架转轴中心至底板内侧为 50 mm；短 U 支架为 30.01 mm。通过转接板和小 U 连接件连接后，每指两根转轴的中心距为 67.5 mm。张开时垫片最高点距手掌底面 139.01 mm；包括掌下露出的绳端，整体包络约为 160 × 190 × 148.414 mm。

小 U 连接件新增四个直径 2.4 mm 的安装孔，以及一个直径 2.4 mm 的导绳孔。安装孔在其背板局部坐标 `(x,z)=(±12,±8)`；导绳孔位于 `(14,-15)`，钻孔方向为原零件的 Y 轴。长／短 U 支架与金属舵盘的实体未作修改。手掌和转接板具有相应安装孔与绳孔。

## 绳索与回弹

每根绳索参考直径为 0.8 mm，从掌下穿过根部支架、指间支架，终止于指尖锚点。牵引入口留在掌下，便于后续连接远置电机、卷线轮或差动机构。本版采用三根可独立拉动的绳索，没有假设一个电机同时拉动三指。

按当前折线绳路计算，张开时每根绳约 138.01 mm，预弯曲时约 124.17 mm，几何缩短量约 13.84 mm。这些长度仅为模型中显示的绳段，不包括卷线轮、远置驱动路径、打结和张紧余量；不能据此直接确定最终裁绳长度。

这是可导入和继续修改的结构初版。驱动电机、卷线轮、回弹弹簧／弹性件、紧固件及真实导绳衬套尚未完成选型和实体建模。原支架的空腔、孔位及新增背板孔可用于后续安装，回弹件需要按实际布置进一步设计。模型中的关节轴直径 2.8 mm、衬套内径 3.2 mm／外径 7.8 mm 是几何配合参考，未进行承载与寿命校核。

预弯曲角度用于结构与绳路检查，不是张力平衡仿真的结果。实际每指两个关节的弯曲分配还取决于回弹刚度、摩擦、绳张力和物体接触；CAD 中的绳索是静态实体，不是柔性绳索求解器。

## 已完成的验证

- 12 个原零件 STEP 均被 Open CASCADE 重新读取为一个有效实体，体积为正。
- 两个完整 STEP 均重新读取为 58 个有效实体。
- 两个交付姿态以及七个中间姿态检查非预期实体相交，报告阈值为 0.02 mm³。
- 绳端进入自身锚点的少量交叠作为有意的连接单独报告，不视为结构干涉。
- PNG 预览直接由装配几何三角化生成，已进行视觉检查。

整机 STL 的检查结果保存在 `mesh_report.json`：法向绕序一致，但整体水密性检查未通过，因此只作为预览网格。打印时应从单独零件的 STEP 导出并检查网格。

这些验证证明文件可被 CAD 内核读取并支持当前几何布局；尚未在本地 SolidWorks 中实际打开验证，也不代替连续运动、抓取动力学或加工装配验证。

## 重新生成

在具有 Python 3.13 和依赖安装权限的环境中，从仓库根目录运行：

```sh
python3 -m venv /private/tmp/hand-cad-venv
/private/tmp/hand-cad-venv/bin/python -m pip install -r descriptions/new/requirements.txt
XDG_CACHE_HOME=/private/tmp/hand-cad-cache /private/tmp/hand-cad-venv/bin/python descriptions/new/build_hand.py --convert
```

不需要重新转换源零件时省略 `--convert`。PNG 通过 VTK 深度缓冲渲染生成，需要可访问的本机图形会话；无图形会话时增加 `--skip-preview`。脚本路径解析不依赖当前工作目录。修改脚本中的 `FINGERS`、手掌尺寸、绳索偏置或姿态角即可重新导出；脚本会检查实体、重新导入 STEP 并进行干涉检查，有未解决问题时以非零状态退出。

SolidWorks 转换使用随本目录保存的开源 [sldprt2step](https://github.com/BlinkingSun/sldprt2step)，许可和声明保留于 `tools/vendor/sldprt2step/`。转换报告记录原文件 SHA-256 和转换器警告；其中侧面支架、窄 U 支架由导入特征中的实体恢复，这两个零件未用于本次装配。三维建模与实体检查使用 CadQuery / Open CASCADE。
