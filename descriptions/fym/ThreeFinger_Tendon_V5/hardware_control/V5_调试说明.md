# V5 控制说明

`servo_host.py` 和原有说明是课程仓库程序的未改动副本，保留用于逐个识别、读取和点动现有总线舵机。此版本没有把机械 CAD 角度假装成真实舵机控制标定，也未在硬件上测试通信。

本手使用三路舵机牵引三根绳。不要直接运行原项目面向四个关节的角度动作或 `MOVE4` 示例来控制本手。先断开绳，用原有交互式 `READ id` / `MOVE id pos time` 确认舵机 ID、PWM 零点、收绳方向、角度与 PWM 的换算和电源能力，再独立对三指做小步进。

卷线轮绳中心半径 10.9 mm，机械换算为 `收绳 mm = 10.9 × 转角 rad`。一根绳子控制两个被动关节，不能从一个舵机位置唯一反推出两个关节角度。几何参考姿态的两关节角不是可直接下发的两个 PWM。

STEP 无法确定舵机实际转角、转矩、堵转电流或电子限位。根据实物确定这些参数后，再建立零点和最大收绳量；通电装配、穿绳及试夹顺序见装配说明。

V5 先根部预弯、再包覆的收绳预设见 simulation/grasp_profiles.json。预设单位是毫米，不是PWM；换算为卷线轮角度后仍须实测舵机零点、方向和PWM比例。无需力传感器，但必须先标定并人工观察单指。仿真升降高度为虚拟夹具坐标，不是第四个舵机的动作指令。
