# SolidWorks 打开与继续编辑

## 先看整机

解压全部文件，打开根目录 `00_OPEN_IN_SOLIDWORKS.step`。这是一个产品内的多实体整机，便于避免逐个弹出零件文件；颜色显示可能受导入器选项影响。看配色和零件名称，用 `cad/OPEN_ASSEMBLY.step`。

Windows 没有 STEP 文件关联时，不要双击老师的单独舵机文件来找整机。打开 SolidWorks 后用“文件 → 打开 → STEP”选整机文件。导入单位选择毫米，缩放保持 1:1。按 F 缩放到整机，空格切换等轴测；沿红色为牵引绳、黄色为回弹皮筋查看。

如果 STEP 被导入成关联外部文件，后续想直接改实体，可以根据 SolidWorks 版本先断开导入链接，再用移动面、切除、孔、直接编辑等功能。要改指长、轴距或宽度，也可以改本包源码重新生成。原生参数化草图不随 STEP 传输。

## 需要在装配环境里转动时

1. 导入装配版，保存为一个独立的本地 SLDASM 工程，并保留所有生成的 SLDPRT 零件。不能只发送 SLDASM 而漏掉引用零件；修改后分享请用 SolidWorks “打包”功能。
2. 固定掌板/底座，把三个指根与掌板完全约束。舵机外壳、托盘、上盖、导绳器都固定在掌板系统中。
3. 每根近端指节的下轴孔与相应指根孔设同轴配合。轴向用一侧面对齐或距离配合，保留约 0.3 mm 的单侧垫片间隔，禁止把转动也锁死。
4. 每根远端指节与近端上轴孔同样设同轴和轴向配合。转轴、螺母、垫圈按各自连接部件固定或合理允许转动，避免把螺丝配合再次锁死手指。
5. 指根局部 X 轴为关节轴，向内屈曲为局部 +X 转动。三指根位置分别为 `(0,65,24)`、`(-56.292,-32.5,24)`、`(56.292,-32.5,24)` mm，绕 Z 方位角 0°、120°、240°。近端上轴与下轴距离 62 mm。
6. 开始可观察根关节 0-35°、指间关节 0-60°范围，使用碰撞检测；这一范围不是每一种三指角度组合都能无碰撞的承诺。实物回弹和软指垫接触决定欠驱动角度，不能给两个关节强加固定比例齿轮配合。

红绳和黄色皮筋是静态参考实体，做运动检查前可隐藏；直接拖动手指不会让这些实体自动变形。要观察新的静态角度，用源码生成新姿态；做真正的腱绳动力学，需另建柔性/张力模型，本包没有声称提供 SolidWorks Motion 仿真。

`checks/*_instances.json` 给出全部实例的刚性变换矩阵，平移单位 mm；本包把几何变换后写入 STEP，装配颜色和名称由装配节点保存。
